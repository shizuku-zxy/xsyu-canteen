# 西石大 · 今天吃啥

面向西安石油大学校园的食堂推荐应用。把档口、菜品、价格、份量、**标签**和图片整理成可浏览、可筛选、可提问的结构化数据；不填 API Key 也能使用本地规则推荐。

## 运行

要求：Python 3.10+，无第三方依赖。

```bash
python 03_服务端/app.py --port 8100
```

浏览器打开 http://127.0.0.1:8100/。

也可以双击 `03_服务端/启动服务.bat`（Windows）。

## 目录

- `02_前端/`：单文件前端 index.html（内联 TREE 即浏览/搜索/筛选的数据源）+ 本地图片/字体
- `03_服务端/`：Python 标准库 HTTP 服务、规则解析、推荐引擎、SQLite DAO、标注/数据修订脚本
- `04_数据库/数据/app.db`：内置食堂菜品数据（128 档口 / 1888 道可推荐菜品）
- `03_服务端/tagging/`：按楼层复核的菜品标签终稿（6 个楼层，可审计、可重放）

## 无 Key 规则

不填模型 Key 时自动使用本地规则：

- 位置：校区、食堂、楼层、档口
- 预算：15块以下、10块左右、8到12块
- 品类（粗）：米饭、快餐、面、粉、水饺包子、麻辣烫香锅、汉堡披萨、粥汤、小吃饼类、甜品、饮品、轻食
- **细分**（2026-11 新增）：馒头、馍、花卷、包子、饺子、馄饨、饼、夹馍、凉皮、粥、稀饭、汤、
  米线、米粉、螺蛳粉、饭团、炒饭、盖饭、汉堡、披萨、炸鸡、麻辣烫、冒菜、香锅、沙拉、豆浆、油条、
  煎蛋、卤蛋、奶茶、咖啡、蛋糕、蛋挞……
- 特点：早餐、素食、低卡、自选、荤菜、素菜、主食
- 主料、口味、做法标签
- 否定：不要、没有、不吃、不含、别放、忌口、过敏；**反义词**：查「稀饭/粥」自动排除「米饭」
- 自然说法：便宜一点、想省点钱、想要喝的、吃虾、海鲜面 等
- **直接命中优先**：说「馒头」时菜名里真含「馒头」的排最前，其次才是同义标签（馍）的菜

## 推荐路由（窗口 / 菜品）

- **搜索框**：始终先展示窗口/档口结果，顶部一行可切换「窗口 / 菜品」。
- **小油对话**：按意图路由——
  - 说「窗口、档口、哪家、食堂、楼层」→ 先走窗口层；
  - 说「菜名、食材、口味、预算、忌口」→ 走菜品层；
  - 含糊问法 → 先给窗口，再在同一个气泡里切换到菜品。
- 窗口数量按偶数向上取整：3→4、5→6。
- 无 Key 时使用本地规则和随机化话术，不依赖外部 API。

## 可选 LLM

复制示例配置：

```bash
copy 03_服务端\llm_config.example.json 03_服务端\llm_config.json
```

填写自己的 OpenAI 兼容 `api_key` 后重启服务；不填时自动回退本地规则。llm_config.json 已加入 .gitignore，不要提交真实 Key。

## 数据维护（2026-11）

改了数据库里的价格 / 标签 / 图片后：

```bash
# 1) 重新合并标签终稿（改过 lexicon.py 时；会刷新 tag 表、FTS、128 个档口统计）
python projects/03_服务端/tag_dishes.py --merge-dir projects/03_服务端/tagging --apply

# 2) 把 DB 数据重新生成到前端内联 TREE（改了价格/标签/照片后必须跑）
python projects/03_服务端/export_tree.py --apply

# 3) 回归自测（64 项，含馒头/稀饭/反义词/直接命中/预算/忌口/窗口等）
python projects/03_服务端/selftest_queries.py
```

历史数据修订脚本（幂等）：`fix_huxian_menu.py`（户县软面照片 + 4 道缺价 + 煎蛋/卤蛋）、
`fill_missing_prices.py`（其余 34 道缺价：18 道价目表实拍 + 16 道同类参考价）。

## 技术栈

Python 标准库 ThreadingHTTPServer + SQLite + 原生 JavaScript/CSS。前端为单文件 SPA，后端按 routers / services / dao 分层。

## 说明

数据仅用于校园食堂信息展示与推荐演示；菜品、价格和图片以现场为准。
